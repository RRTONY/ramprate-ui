**Live end-to-end flow test attempted 2026-09-16, INCONCLUSIVE due to a client-side delivery quirk (not necessarily a code bug):** posted ~5 real `doPost` Stage 1 test submissions (`legal_entity_name: "TEST - Claude QA flow check <timestamp>"`, `email: web.master@ramprate.com`, `primary_contact_name: "Test"`) directly against the live `GOOGLE_APPS_SCRIPT_URL` from `.env` via curl/node, per the user's request to test the whole flow using their own email. Findings:
- Read-only `doGet` calls (safe, no side effects) succeeded with clean `200` JSON responses **2 out of 3** times; the 3rd returned a generic Google Drive "unable to open the file" error page.
- Every `doPost` (write) attempt (4/4) returned `405` with that same Drive error page instead of this script's own JSON response - never once got a clean `{"ok":true}` back.
- Because Apps Script Web Apps execute `doPost` server-side on the FIRST request (to `script.google.com/.../exec`) and only redirect the client to a separate one-time `script.googleusercontent.com/macros/echo?...` URL to fetch the already-computed response, **a failure to fetch that echo URL does NOT necessarily mean `doPost` itself failed** - the write/email-sending may have gone through fine even though the client-side response never arrived. This session could not distinguish "my script errored" from "Google's response-delivery hop is just flaky" without checking the Sheet/inbox directly (no Sheets/Gmail API access this session).
- **This needs the user to verify directly**: (a) check the Sheet for however many `TEST - Claude QA flow check ...` rows actually landed, (b) check `web.master@ramprate.com` for however many "Confirmation of Your Supplier Application to RampRate" (Email 1) + "New Stage 1 Supplier Application" (staff alert) emails arrived, (c) **most reliable check**: submit one real test through the actual live `https://ramprate.com/supplier-intake` page in a browser, which sidesteps all of this curl/redirect complexity and is the definitive test of whether the intake pipeline is healthy right now.
