**Testing gotcha:** verifying scroll-reveal via Playwright's `page.screenshot({fullPage: true})` gives false negatives — that capture mode renders content beyond the real viewport without running normal paint/`IntersectionObserver` checks for that region, so reveal-animated elements show as still-hidden even though real user scrolling triggers them correctly. To verify scroll-reveal, drive a real incremental `scrollTo` loop with a `waitForTimeout` between steps and check computed `opacity` at each step, not a single `fullPage` screenshot.
